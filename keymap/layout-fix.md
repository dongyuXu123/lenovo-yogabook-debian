# 回车 / 反斜杠 错位：坐标推导

## 现象

- 按回车**左半边** → 输出 `\`
- 按回车**右半边** → 输出回车（正常）
- 按 **`\` 键** → 输出回车

## 数据来源

`/etc/halo-keyboard/layout.csv` 实际是软链到 `layouts/YB1-X9x-pc105.csv`（PC-105 布局）。

原始相关三行：

```
43: 29;13,7;226,6;15,4;ENTER;28;;      # 右上那颗 —— 实际是物理 "\"
56: 46,5;13,7;217,5;11;BACKSLASH;43;;  # 右下角 —— 实际是回车的左半
57: 42,7;13,7;231,5;10,5;ENTER;28;;    # 右下角上部 —— 回车右半（正确）
```

## 实测坐标

用 evtest 读 Goodix 触摸面（`/dev/input/event6`），依次按 回车左半、回车右半、`\`：

```
(703, 1771)   回车左半
(707, 1895)   回车右半
(843, 1886)   "\" 键
```

传感器空间 1200×1920（`hardware.csv`：resolution 1200×1920，139×242mm，rotation 270）。
映射到布局表空间（mm）：

```
x ≈ Y_sensor × 242/1920
y ≈ (1200 − X_sensor) × 139/1200
```

代入：

| 实测点 | 表空间坐标 | 原始表落在 | 物理含义 |
|---|---|---|---|
| (703,1771) | (223.2, 57.6) | BACKSLASH (217.5–228.5, 46.5–60.2) | 回车左半 |
| (707,1895) | (238.8, 57.1) | 小 ENTER (231.5–242, 42.7–56.4) | 回车右半 |
| (843,1886) | (237.7, 41.3) | ENTER (226.6–242, 29–42.7) | `\` 键 |

结论：物理回车是**右下角一颗横跨 217.5–242 的宽键**，物理 `\` 在它上方；
原表把这两块标反了，且把回车拆成了 BACKSLASH + 小 ENTER 两段。

## 修正

```
43: 29;13,7;226,6;15,4;BACKSLASH;43;;
56: 46,5;13,7;217,5;24,5;ENTER;28;;
57: 42,7;13,7;231,5;10,5;ENTER;28;;   # 保留，覆盖回车右上角
```

即：右上那颗改成 `\`，右下那颗加宽成 24.5mm 的 `ENTER`。

应用后 `systemctl restart halo-keyboard` 生效，重启后保持（改的是持久配置文件）。

回滚：`cp /etc/halo-keyboard/layouts/YB1-X9x-pc105.csv.bak /etc/halo-keyboard/layouts/YB1-X9x-pc105.csv`
